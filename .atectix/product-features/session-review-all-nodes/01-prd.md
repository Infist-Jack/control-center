# 中控会话复盘：扫描全部节点

状态：2026-10-02 用户确认业务逻辑并明确要求修复 bug、安装必要插件、扩展全部节点信息收集；实现与自动化验证完成，已安装到中控并确认插件运行。真实扫描覆盖全部 4 个登记节点，3 个成功、1 个离线。

## 用户需要

用户要求审查 PR #1「会话复盘」，通过后安装到中控，并扩展为扫描所有节点。在中控的一个页面查看各节点的 Claude Code / Codex 会话，了解工作时间、并行情况和确定性的决策点。

原 PR 只扫描插件所在机器。当前审查发现的问题见 [审查报告](review/pr1-review.md)，应在安装前修复并验证。

## 范围

- 中控提供统一「复盘」入口，覆盖中控已登记、具备连接凭据的所有节点，包含中控本机。当前登记数量为 4，名单随登记变化，不在代码或文档中写死机器信息。
- 支持选择全部节点或单个节点；默认全部节点。项目选项只显示项目名称，不加节点前缀；内部保留项目的节点归属，避免把不同机器上的项目误合并。
- 保留日期范围、时间线、消息详情和确定性决策点。始终纳入全部分支，不提供分支筛选；终端直接启动的会话也纳入。
- 当前范围包括已有会话的正确解析；旧版记录、跨天恢复、分叉和子会话不能造成静默遗漏或重复统计。
- 不包含 AI 归纳、自动分类、定时扫描、会话干预、向外部应用发送消息或报告，也不登记尚未接入中控的机器。

## 页面行为

1. 打开页面加载当前范围，点击「刷新」直接重新扫描，一次操作完成。节点、项目、日期可以切换；分支始终为全部，旧客户端遗留的分支筛选参数也不生效。
2. 每个节点展示读取中、完成、离线、失败或不可用的状态。某个节点失败时，其余节点的结果照常展示，可以重试失败节点。
3. 会话行和详情始终显示所属节点。会话标识相同但来自不同节点的记录不互相覆盖；同一节点内继续折叠恢复副本和子会话。
4. 日期筛选和时间轴使用统一时区，默认 Asia/Singapore，页面明确显示时区。相同瞬间在跨节点时间线上对齐；跨零点活动归入对应的日期。
5. 汇总仅计算成功返回的节点；有节点未完成或失败时，明确标注结果不完整，不把失败当成零会话。

## 数据与失败边界

- 原始会话记录保留在来源节点；中控展示和保存的抽取内容先脱敏，JSON 中的密钥、token 等常见表示也覆盖。
- 单个记录损坏时保留可用结果并指出失败；缓存写入失败与原始记录解析失败分开说明。
- 长任务展示进度，离开页面不取消。返回后可重新获取状态；插件重启造成任务失效时允许直接重新扫描。
- 超出范围上限时提示收窄范围，不静默截断，也不让重复副本、应折叠子会话或范围外活动误占限额。
- 不采集配对链接和凭据文件，不把它们写入结果或日志。

## 验收标准

1. 中控一次扫描覆盖当前全部登记节点，每个节点有明确状态；故意让一个节点不可达，其余结果仍可用，汇总标注缺失。
2. 两个节点具有相同会话 ID 或同名项目时，列表、筛选、消息详情均归属正确。
3. 跨日、超过 30 天后恢复、旧版 Codex 子线程、多层 fork 均有回归用例；只在所选日期有活动的会话出现，并包含全部分支。
4. 中断后恢复的长间隔不被连续记为运行；并发扫描不产生缓存竞争导致的假解析错误。
5. 合成凭据样例经扫描后，不在中控缓存、列表或详情中保留原值；扫描不修改来源记录。
6. 窄屏与宽屏可用；空结果、节点失败、任务过期状态下均可清除筛选或重试。

## 2026-10-03：后台定时采集与快照读取

- 中控插件每 5 分钟后台采集全部登记节点，预热今天、昨天、最近 7 天，脱敏结果保存在仓库外的插件数据目录。
- 页面打开和节点、项目筛选只读本地快照；后台更新继续展示旧结果，并显示采集时间。提供「立即更新」入口。
- 自定义日期范围首次访问时后台补采并保存，最近 8 个自定义范围加入周期采集。日期范围按新加坡时区解析，跨天不复用错误日期的数据。
- 离线节点保留同日期范围内的上次成功数据并标注时间。重启恢复已有快照；慢任务不重叠，插件卸载或重载时取消定时器和采集。
- 汇总文件只存运行数据，不提交 Git；原始会话留在来源节点，消息详情维持按需分页读取。

## 2026-10-03：任意节点安装，清单可选

- 插件可以装在任意一台 Paseo daemon 上，始终复盘本机；只有在这台机器配置了 `paseo-nodes-use` 的节点清单和配对链接时，才顺带复盘清单里的节点。被采集节点不需要安装插件或其他服务。
- 没有清单、清单目录不存在或读取失败，都不能让页面失效：本机结果照常返回，页面说明原因。
- 清单目录、仓库目录和时区都是插件设置，留空即默认值；中控沿用现有默认目录不需要改配置。时区默认取 daemon 本机时区，跨节点时统一填写。
- 同一台机器既被中控采集又装了插件时，抽取缓存互不覆盖。
