# Paseo 会话复盘（session-review）

状态：2026-10-01 产品设计讨论中。首版范围、三层展示规则、决策点只取确定性事件、归纳 runtime 与提示词预设已获用户确认；本文待用户确认后进入实现方案。

## 用户需要与结果

用户在 Paseo 里选一个工作区和一个日期范围，看到这段时间这台机器上全部 agent 会话的时间线：每个会话做了什么、持续多久、哪些时刻 agent 停下来问他、他在哪里打断或纠正了 agent、agent 把什么写进了记忆，以及多个会话如何并行。可选地让一个 coding agent runtime 按用户自己写的提示词做归纳。目的只有一个：事后 review 和反思，不是工程监控。

## 已确认的基础

- Paseo 0.9.2 原生插件：工作区面板、侧栏页、插件 RPC（30 秒超时，长任务走启动与轮询）、服务端以 daemon 用户在节点本机运行。代码放在 control-center 的 `plugins/session-review/`，不改 Paseo 源码。
- 会话原始记录都在节点本机：Claude Code 为 `~/.claude/projects/<目录slug>/<session>.jsonl`，Codex 为 `~/.codex/sessions/<日期>/rollout-*.jsonl`。Paseo 的 `~/.paseo/agents/*.json` 记录每个 agent 对应的 provider 会话 id、工作区和目录。
- 两类记录都带时间戳，并以结构化方式记录：用户消息、助手文本、工具调用及参数、提问工具及其回答、用户打断、Codex 的 fork 与子线程关系、每轮 token 用量。Codex 的推理内容加密，不读。
- 归纳 runtime 复用本机登录态，以子进程方式调用：`claude -p --output-format json --json-schema`、`codex exec --json --output-schema --ephemeral`（只读沙箱）、`opencode run`。本机当前未安装 opencode，其调用方式在实现阶段验证。

## 首版范围

一个名为「复盘」的工作区面板，加一个同名侧栏页用于跨工作区选范围。内容分三层：会话时间线、决策点与并行图、归纳。归纳为可选操作，手动触发。

首版不包含：批注与复盘笔记、一键生成飞书文档、启发式决策点（问号结尾、否定词匹配等）、Codex 分叉树与 guardian 审查的展示、工具调用次数与 token 作为主视图内容、跨节点聚合、定时自动运行、对 agent 的任何干预。

## 聚合规则

- **单位是一个 provider 会话。** Codex 由 `forked_from_id` 产生的 fork 作为源会话下的分支展示；带 `parent_thread_id` 的子线程（guardian 审查等）和 Claude 子代理折叠进父会话，不单列。
- **归属按目录。** 会话的 cwd 落在某个 Paseo 项目的根目录或其 worktree 之下，就归到该项目和工作区。由 Paseo 创建的 agent 直接用其记录的工作区；终端里直接启动、未经 Paseo 的会话同样纳入，标记「未纳管」。
- **范围三个维度：** 工作区，默认当前；日期范围，默认今天，按节点本地时区；分支，可选，按会话记录的 git 分支过滤。
- 一个会话跨越日期边界时，按其起始日归入。

## 页面与交互

### 范围选择

面板顶部：日期范围（今天、昨天、最近 7 天、自定义）、分支过滤。侧栏页多一个工作区选择器，其余相同。切换范围只读本地文件，不触发归纳。

### 概览

一行摘要：时间跨度、会话数、最大并行数、总活跃时长（重叠部分只算一次）、等待用户的总时长。

### 会话卡

按开始时间排序，每张卡只展示：

1. 标题：取用户首条指令，最长 60 字，超出以省略号截断；旁边一个 provider 标签（Claude / Codex），不显示模型与权限模式。
2. 起止时间、活跃时长、用户发送的消息数。
3. 「未纳管」标记（如适用）；fork 分支缩进挂在源会话下。
4. 结局标签：交付、废弃、被推翻、未完成。由归纳层填写，未归纳时留空。

卡上不展示最后一条消息、改动文件数、commit、工具与 token 统计。点开卡片进入该会话的详情：按时间排列的用户消息与助手文本，以及该会话的决策点。

### 决策点

只取三类确定性事件，每条一行：时间、类型、原文摘录（不超过 100 字）、agent 随后做了什么（取其下一条文本的首句）。

| 类型 | Claude Code 的判定 | Codex 的判定 |
| --- | --- | --- |
| agent 提问 | `AskUserQuestion` 工具调用，答案取对应的工具结果 | `request_user_input_async` 调用及用户的回复记录 |
| 用户打断或拒绝 | 用户记录含 `[Request interrupted by user]`；工具结果含 CLI 固定的权限拒绝文案 | `turn_aborted` 且 `reason` 为 `interrupted` |
| 写入记忆 | `Write` / `Edit` 的目标路径位于 `.claude/projects/*/memory/` | 首版不判定（其工具为通用 exec，无确定性标记） |

不做任何基于文本模式的推测。判定规则集中在一处，每条规则附带记录样例作为测试。

### 并行图

横轴为时间，一行一个会话，按开始时间排。三种段：agent 在运行（Codex 取 `task_started` 到 `task_complete`；Claude 取用户消息到该轮最后一条助手记录）、等待用户（一轮结束到用户下一条消息，且会话随后继续）、空白为闲置或已结束。决策点以圆点标在对应位置，点击定位到决策点列表。

颜色只取 `theme.colors`：运行段用 `accent`，等待段用 `surface2` 或等效中性色，圆点用 `foreground`。深色与浅色主题下都要可辨，不使用固定色值。紧凑布局下退化为表格：每会话一行，列出起止、活跃、等待。

### 归纳

面板内一个「归纳」区域：选择 runtime（默认 claude，可选 codex、opencode）、选择提示词预设、点击运行。输入只包含前两层的脱敏抽取物，不含原始记录。输出结构固定，预设只影响归纳的注重点：

- 每会话：目标一句话、结局（交付 / 废弃 / 被推翻 / 未完成）、被推翻的原因、如果重来会怎么做。
- 每天：时间分桶（环境、理解、建设、部署、沟通、其他）、被推翻的决策清单、等待最久的三处、一句话总结。

结果写回会话卡的结局标签和一个日级归纳区。结果按「范围 + 各会话文件修改时间 + runtime + 预设内容哈希」缓存，重复运行只处理变化的会话；不自动运行。

### 提示词预设

预设是带名称的一段文字，用户可以保存多个并任选其一。内置一个「通用复盘」预设作为默认，不可删除但可复制。面板内可新建、编辑、复制、删除、设为默认。预设只写注重点（例如「重点看我在哪里浪费了时间」「只关注我和 agent 的分歧」），固定的输出结构由插件维护，用户不需要也不能改输出格式。预设存为节点本机文件，不随插件代码分发。

### 脱敏

抽取时统一打码：形如 API key 和 token 的字符串、`Bearer` 后的值、URL 路径中长度超过 20 的随机段、`.env` 类文件内容回显。打码后的抽取物才会落盘和送入归纳。

## 失败、重试与离开页面

- 某个会话文件无法解析时，其余会话照常展示，该会话标「无法解析」并给出文件路径。
- 归纳 runtime 失败时显示错误与 runtime 的原始输出尾部，保留上一次成功的归纳结果。
- 抽取与归纳都是后台任务：离开面板不取消，返回后可查看进度与结果；重复点击不会重复启动同一范围的任务。
- 插件重启后缓存仍在，未完成的任务不续跑，重新触发即可。
- 范围内会话数量超过上限（首版 200 个）时提示收窄范围，不静默截断。

## 验收标准

1. 在真实节点上选择一个工作区和「今天」，面板列出当日全部 Claude 与 Codex 会话，含终端直接启动的会话并标「未纳管」；Codex fork 挂在源会话下，guardian 子线程不出现。
2. 会话卡只含标题、provider 标签、起止、活跃时长、消息数、未纳管标记和结局标签；标题不超过 60 字。
3. 决策点列表中的每一条都能回溯到记录里的一个结构化事件；用 2026-09-30 的记录验证：至少能找出 AskUserQuestion 的 6 次提问、用户的 2 次打断、Claude 的 10 次记忆写入、Codex 的 3 次提问。
4. 并行图在 Paseo 的深色与浅色主题下均可辨认运行段、等待段和决策点；390px 宽度下退化为表格且无横向溢出。
5. 用 claude runtime 对同一范围运行归纳两次，第二次不重新处理未变化的会话；切换预设后重新归纳，输出结构不变。
6. 预设可新建、编辑、删除并在归纳时选用；插件重启后预设仍在。
7. 抽取物与送入 runtime 的内容中不含记录里出现过的 token 与 key（用 2026-09-30 记录中已知的凭据样例做负向检查）。
8. 归纳 runtime 失败、会话文件损坏、离开页面再返回三种情况下，面板行为符合「失败、重试与离开页面」一节。
